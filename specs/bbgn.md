# BBGN — IKOS-based private real summation (Balle, Bell, Gascón, Nissim, CCS 2020)

Source: arXiv:2002.00817 (latest v3; sha256 prefix 2ebadebcd0ea9f43, downloaded 2026-10-30).

## Protocol (Theorem 5.1 / Theorem 6.2 construction)
- Local randomizer R_{α,m,p,q} (Algorithm 6): x̃ = ⌊xp⌋ + Ber(xp − ⌊xp⌋) (precision p; we set **p = K**, the same
  adjacent-grid unbiased quantiser as PW-Sum); y = x̃ + Polya(1/N, α) − Polya(1/N, α) in Z_q; split y into additive
  shares mod q.
- Secure summation: IKOS with randomized inputs, **Corollary 6.1**: m shuffled shares through m parallel shufflers plus
  one unshuffled share per user (m+1 messages), worst-case statistical security σ when m ≥ 3, N ≥ 19, σ ≥ 1, with
  **m = ⌈(2σ + log2 q)/(log2 N − log2 e)⌉ + 1** (eq. (4)).
- Analyzer A_{N,m,p,q} (Algorithm 5): z = Σ messages mod q; if z > (Np + q)/2 then z ← z − q; output z/p.
- q: Theorem 5.1 takes q = ⌈2Np⌉; we use q = ⌈2NK⌉.
- **Noise is generated by users** (Polya shares); not robust to user–analyzer collusion in the PW-Sum sense.

## Privacy
- **Lemma 5.2**: σ-worst-case-secure exact summation ⇒ (ε, (1 + e^ε) 2^{−σ})-DP real summation with the distributed
  DLap noise; the ε part is the discrete Laplace mechanism DLap(α), α = e^{−ε/p}, sensitivity p on Z.
- **Corollary 6.1** (via Theorem 6.1): worst-case security σ for the given m.
- Recipe: σ = ⌈log2((1 + e^ε)/δ)⌉ so that (1+e^ε)2^{−σ} ≤ δ; m from eq. (4); check m ≥ 3, N ≥ 19, σ ≥ 1.
- Neighbouring: replace-one.
- Lemma 5.1 / eq. (3) (single shuffler) contains an unspecified O(1) constant and is NOT used.

## Estimator and analytic MSE
Σ_i (Polya_i − Polya'_i) ~ DLap(α) exactly ([16] in the paper). Error = (Z + Σ_i (x̃_i − y_i p))/p with Z ~ DLap(α):
MSE = 2α/((1−α)² p²) + Σ f_i(1−f_i)/p², plus the mod-q wrap event, which requires |Z| > (q − Np)/2 ≥ Np/2 and has
probability ≤ 2α^{Np/2}/(1+α) (reported; numerically < 1e-300 for our N).

## Communication
m + 1 messages per user, each ⌈log2 q⌉ bits. Bytes (analytic, ECIES as for PW-Sum): ℓ = 48 + ⌈⌈log2 q⌉/8⌉ per message,
counted on both links (user→shuffler(s)→analyzer; the unshuffled share goes user→analyzer, counted once), /N.

## Parameter selection
K: smallest K with 2α/((1−α)²K²) + N/(4K²) ≤ V = 2(1+γ)/ε² (bytes are non-decreasing in K through q; checked
numerically). σ, m from δ as above.

## Simulation shortcut (equivalence proof)
Additive shares sum (mod q) to y_i, so the analyzer's z = Σ y_i mod q = Σ x̃_i + Z mod q; when no wrap occurs the
correction step returns Σ x̃_i + Z exactly. We sample Z ~ DLap(α) directly (difference of two geometrics), simulate
quantisation per user, and count wrap events (expected 0).

## Deviations
- Multi-Shuffler model (m parallel Shufflers plus one unshuffled message). Its trust assumption is stronger than that of a
  single Shuffler: the worst-case security of Corollary 6.1 relies on m independent honest Shufflers and on the share sent
  directly to the analyzer.
- Precision p = K chosen by our MSE target instead of p = √N (Theorem 5.1 uses √N for the O(1/ε²) rate).

## Questions
- None blocking. The DLap(α) noise makes the ε-part identical to the central discrete Laplace mechanism; the method's
  MSE is therefore exactly central-discrete for the chosen K.
