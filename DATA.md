# Datasets

The raw data are public and are not redistributed here. Download them into the layout below and set `PWSUM_DATA` to its root
(default `./data`). Then run `bash scripts/run_m0.sh`, which makes the raw files read-only, cleans them, compares their checksums before
and after, and writes `processed/values.npy` (float64 in $[0,1]$) for every dataset.

```
$PWSUM_DATA/
  SF/raw/export.csv
  ACS/raw/csv_pus.zip
  Taxi/raw/yellow_tripdata_2025-01.parquet ... yellow_tripdata_2025-04.parquet
  Synthetic/            (generated by scripts/m0_synthetic.py)
```

Common rules: each dataset has a public bound $X_{\max}$ fixed before looking at the data. Values are clipped at $X_{\max}$ and divided by it;
all methods use the sum of the clipped, normalised values as ground truth. The neighbouring relation is replace-one over the cleaned records.

## SF: San Francisco employee compensation

- Source: DataSF *Employee Compensation* (88g8-5mnd), full CSV export, https://data.sfgov.org/City-Management-and-Ethics/Employee-Compensation/88g8-5mnd
- Our file (downloaded 2026-10-30): `export.csv`, SHA-256 `0a5fe489be3ee1b77b020bb85b1cc87b98962f3219e3861c32e7b048b8b0ad38`. The portal is updated over time; a new export can differ (see the `data_as_of` column).
- Cleaning: rows with `Year Type = Fiscal` and `Year = 2026` (42,930); `Total Compensation` parsed; rows ≤ 0 removed (2 negative); $X_{\max}=500{,}000$ USD.
- Result: $N=42{,}928$, 0.80% clipped, normalised mean 0.349. Privacy unit: one compensation record (the export has no employee identifier).

## ACS: American Community Survey PUMS

- Source: ACS 2024 1-Year PUMS person records, 50 states + DC, https://www2.census.gov/programs-surveys/acs/data/pums/2024/1-Year/csv_pus.zip
- Our file: `csv_pus.zip`, SHA-256 `afdc6d90c6e2f0bab365ed32d95ba4c4d8ac651162f46ac7861295b2dc469894`.
- Cleaning: blank `PINCP` removed (510,098 records, all with age < 15); negative `PINCP` set to 0 (2,936); no person weights, no `ADJINC`; $X_{\max}=100{,}000$ USD.
- Result: $N=2{,}912{,}790$, 13.31% clipped, normalised mean 0.414. Privacy unit: one person record.

## Taxi: NYC yellow taxi trips

- Source: NYC TLC Trip Record Data, https://d37ci6vzurychx.cloudfront.net/trip-data/yellow_tripdata_2025-{01,02,03,04}.parquet
- Our files, SHA-256:
  - 2025-01 `9af277e4c0d3f9deb30644da822981e1e7df6af58313170fd3aa8a474485488a`
  - 2025-02 `037cba555a73663f3a51a2c27816e40e3feb364769942bdf122b9da31e377bd3`
  - 2025-03 `20c4b77cce457b7cfdae77c5069ca7dc91c167f876a41467f4502ab69487a186`
  - 2025-04 `6f98938de9380a3f85600533816f0dc0e6d9b5b210e485d623952bac599bbe28`
- Cleaning: field `trip_distance`; missing, non-finite and negative values removed (none); records above 200 miles removed (721, threshold fixed in advance); zero-distance trips kept; $X_{\max}=20$ miles.
- Result: $N=15{,}167{,}858$, 0.76% clipped, normalised mean 0.157. Privacy unit: one trip record.
- The database workload (`scripts/dbq_run.py`) reads the same four files directly, partitions their row groups and applies the same rules inside a public pickup-time window.

## Synthetic

`src/pwexp/synthetic.py`, values in $[0,1]$, seed `20261101 + 100·index(distribution) + log10(N)`:
uniform; Gaussian $\mathcal N(0.5,0.15^2)$ truncated to $[0,1]$; Zipf with $\Pr[r]\propto1/r$ on $r\in\{1,\dots,1000\}$ mapped to $(r-1)/999$;
$\frac12\mathrm{Beta}(1,19)+\frac12\mathrm{Beta}(19,1)$; and grid midpoints $(k+\frac12)/K$, generated per method's $K$ and used only to check the
quantization bound.
